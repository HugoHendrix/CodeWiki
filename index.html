    • 🛠️ Ferramentas para Diagnóstico de DNS

    DNSChecker

    Permite verificar a propagação de DNS globalmente. Você pode inserir um domínio e ver como os servidores DNS ao redor do mundo estão respondendo. Ideal para identificar problemas de resolução ou propagação.

    dnschecker.org

    DNSHistory

    Exibe o histórico de registros DNS de um domínio. Útil para investigar alterações suspeitas, rastrear mudanças de IP ou entender o comportamento passado de um site.

    dnshistory.org

    Chrome Net Internals (DNS)

    Ferramenta interna do navegador Chrome que mostra o cache DNS local, permite limpá-lo e visualizar requisições DNS feitas pelo navegador. Excelente para testes locais e depuração rápida.

    chrome://net-internals/#dns
