🎨 Design Visual & Recursos Gráficos

 
Link Descrição
unicornicons.com/icons Biblioteca de ícones gratuitos e personalizáveis para projetos de design e desenvolvimento
undraw.co/illustrations Ilustrações vetoriais gratuitas e personalizáveis para projetos web
VectorPortal Banco de vetores gratuitos e livre de direitos
Symbl Ampla coleção de símbolos em HTML e SVG, incluindo emojis, bandeiras, logotipos e redes sociais.
Google Fonts Icons Google Fonts Icons é uma biblioteca de ícones oficiais do Google, oferecendo um conjunto de símbolos de interface do usuário para designers e desenvolvedores. Os ícones estão disponíveis em vários estilos e formatos (SVG, PNG) e podem ser ajustados em peso, preenchimento e tamanho para se adequar a diferentes projetos.
FontPair O site Fontpair é uma plataforma que ajuda designers e criadores a encontrar combinações de fontes gratuitas (principalmente do Google Fonts e Fontshare), já curadas profissionalmente, para usar em projetos de design gráfico e web.


🧰 Ferramentas e Edição de Imagens

Link Descrição
photopea.com Editor online gratuito similar ao Photoshop (suporta PSD, XCF, Sketch)
iLoveIMG Ferramenta online para comprimir, redimensionar, converter e editar imagens em massa
ClipDrop Plataforma de edição de imagens com IA: remoção de fundo, upscaling e ajustes automáticos
Image Resizer Redimensiona, corta, converte e comprime imagens diretamente no navegador
Squoosh Um otimizador de imagens do Google, ideal para quem precisa de controle total. Ele permite ajustar a qualidade e o formato da imagem e visualizar a diferença em tempo real, lado a lado, antes de fazer o download.
TinyPNG Focado na simplicidade, é a ferramenta perfeita para quem precisa de resultados rápidos. Basta arrastar e soltar suas imagens para que ele as comprima automaticamente. É especialmente eficaz para arquivos PNG, mas também funciona muito bem com JPGs


🎛️ Geradores & Customização Visual

Link Descrição
patternpad.com Ferramenta para criar padrões de fundo personalizados
shapedivider.app Gerador de divisores de seção personalizados com SVG/CSS
CSS Background Patterns Gerador de padrões CSS com visualização ao vivo e código pronto para copiar
Subgrid Visualizer Ferramenta interativa para visualizar como o subgrid do CSS funciona, especialmente como elementos filhos (grid items) podem “herdar” linhas do grid pai. Permite brincar com colunas, linhas, gaps etc.
Neumorphism Generator Geração visual de efeitos de “neumorfismo” (soft UI), que é um estilo visual onde sombras internas/externas são usadas para dar relevo suave aos elementos. A ferramenta deixa você ajustar cor de fundo, sombra, blur, raio de borda etc., e ver o CSS gerado.


🌈 Cores e Paletas

Link Descrição
Adobe Color (Imagem) Capta as cores principais de uma imagem e gera paleta automática
Color Wheel Ferramenta para criar e experimentar paletas de cores usando roda cromática
Coolors Coolors é um gerador de paletas de cores ultrarrápido, ideal para designers, desenvolvedores e qualquer pessoa que precise criar ou explorar combinações de cores harmoniosas.
Paletton Ferramenta online para a criação de paletas de cores. O site utiliza a teoria das cores para ajudar designers e usuários a criar esquemas de cores harmoniosos, oferecendo diferentes modos como monocromático, tríade e complementar.
Adobe Color Ferramenta da Adobe para criar, salvar e explorar paletas de cores de forma intuitiva, baseada na roda de cores e em princípios de harmonia. Permite gerar combinações a partir de cores de base ou imagens, além de ser integrada ao ecossistema de softwares da Adobe (Photoshop, Illustrator, etc.).
