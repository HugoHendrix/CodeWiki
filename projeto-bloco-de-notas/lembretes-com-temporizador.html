Lembretes com temporizador e aviso sonoro

O Bloco de Notas tem lembretes para voltar a contatar um motorista. Esta anotação explica como fiz o temporizador, o aviso sonoro e o que acontece quando a página é recarregada.

Guardar o horário de término, e não o tempo restante

Se eu guardasse "faltam 600 segundos", o valor ficaria errado depois de fechar a aba. Guardando o momento em que acaba, o tempo restante é sempre uma conta:

lembretes.push({ id: novoId(), texto, fim: Date.now() + minutos * 60000 });

const restante = lembrete.fim - Date.now();   // em milissegundos

Assim o lembrete continua correndo depois de recarregar a página.

Atualizar a tela a cada segundo

setInterval(() => {
  const total = Math.ceil((lembrete.fim - Date.now()) / 1000);
  tempoEl.textContent = pad(Math.floor(total / 60)) + ':' + pad(total % 60);
}, 1000);

Aviso sonoro com a Web Audio API

function tocarAviso() {
  const ctx = contextoAudio || new AudioContext();
  [0, 0.35, 0.7].forEach((atraso) => {
    const osc = ctx.createOscillator();
    const ganho = ctx.createGain();
    osc.frequency.value = 880;
    ganho.gain.value = 0.15;
    osc.connect(ganho);
    ganho.connect(ctx.destination);
    osc.start(ctx.currentTime + atraso);
    osc.stop(ctx.currentTime + atraso + 0.2);
  });
}
  • Três bipes curtos, sem precisar de nenhum arquivo de áudio.
  • Navegadores só liberam som depois de uma ação do usuário. Por isso criei o AudioContext no clique de "Criar lembrete", e não quando o tempo acaba.

Avisos que não dependem de som

  • O cartão muda de cor e mostra "Tempo esgotado".
  • O título da aba ganha o prefixo "⏰ Lembrete!", que aparece mesmo com a aba em segundo plano.
  • Um elemento com role="alert" e aria-live="assertive" anuncia o lembrete para leitores de tela.
