Modelos de mensagem com campos {{variavel}}

As mensagens padrão do Bloco de Notas têm lacunas que o operador preenche uma vez (veículo, local e horário) e que se repetem em todas as mensagens. Esta anotação mostra a técnica.

O modelo

const modelo = 'Identificamos o veículo {{veiculo}} parado em {{local}} desde as {{horario}}.';

Substituir os campos

function preencher(texto) {
  const dados = {
    veiculo: document.getElementById('m-veiculo').value.trim() || '[veículo]',
    local: document.getElementById('m-local').value.trim() || '[local]',
    horario: document.getElementById('m-horario').value || '[horário]'
  };
  return texto.replace(/\{\{(\w+)\}\}/g, (inteiro, chave) =>
    chave in dados ? dados[chave] : inteiro);
}
  • A expressão regular /\{\{(\w+)\}\}/g encontra tudo o que está entre chaves duplas.
  • A função de substituição recebe o nome do campo e devolve o valor correspondente.
  • Se o campo ainda não foi preenchido, aparece um marcador como [veículo], o que evita enviar uma mensagem com lacuna escondida.
  • Um campo desconhecido ({{outro}}) é mantido como está, em vez de virar undefined.

Deixar o usuário editar os modelos

O modelo guardado é o texto com as chaves, e a mensagem mostrada é o resultado do preencher. Assim, ao editar, o usuário vê e altera o modelo, e ao copiar, leva o texto já preenchido. Os modelos ficam no localStorage (veja Salvar no navegador), e um botão restaura os padrões.

Por que isso agiliza

O operador digita o veículo uma vez e todas as mensagens ficam prontas. Foi o que mais ajudou no registro diário das ocorrências sobre os motoristas.
