Copiar para a área de transferência com plano B

A ação mais usada no Bloco de Notas era copiar um texto para colar em outro sistema. Esta anotação mostra como fiz isso funcionar mesmo quando a API moderna não está disponível.

A API moderna

await navigator.clipboard.writeText(texto);

Funciona só em páginas seguras (HTTPS ou localhost) e pode ser negada pelo navegador.

O plano B com execCommand

async function copiarTexto(texto) {
  try {
    await navigator.clipboard.writeText(texto);
    return true;
  } catch (e) {
    const temp = document.createElement('textarea');
    temp.value = texto;
    temp.setAttribute('readonly', '');
    temp.style.position = 'fixed';
    temp.style.opacity = '0';
    document.body.appendChild(temp);
    temp.select();
    let ok = false;
    try { ok = document.execCommand('copy'); } catch (err) {}
    document.body.removeChild(temp);
    return ok;
  }
}
  • O textarea temporário fica fora da vista, mas selecionável, porque execCommand só copia o que está selecionado.
  • A função devolve true ou false, e a tela mostra "Copiado!" ou "Não foi possível copiar".

Feedback que todo mundo percebe

O aviso vai em um elemento com role="status" e aria-live="polite", para leitores de tela anunciarem o resultado sem mover o foco:

<span class="status" role="status" aria-live="polite"></span>

Dica

Copiar sem nada selecionado ou com campo vazio deve avisar "Nada para copiar", em vez de copiar um texto vazio sem ninguém perceber.
