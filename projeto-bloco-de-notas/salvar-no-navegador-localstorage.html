Salvar no navegador com localStorage

No Bloco de Notas do Operador, tudo o que o usuário escreve (anotações, mensagens, checklist, lembretes) é salvo no próprio navegador, sem servidor. Esta anotação mostra como organizei isso.

Um ajudante com tratamento de erros

O localStorage pode estar bloqueado (modo privado, política da empresa) ou cheio. Por isso encapsulei as chamadas em um objeto que nunca lança erro e que guarda os dados em JSON:

const memoria = {
  ler(chave, padrao) {
    try {
      const bruto = localStorage.getItem(chave);
      return bruto === null ? padrao : JSON.parse(bruto);
    } catch (e) {
      return padrao;
    }
  },
  gravar(chave, valor) {
    try {
      localStorage.setItem(chave, JSON.stringify(valor));
      return true;
    } catch (e) {
      return false;
    }
  }
};
  • JSON.stringify e JSON.parse permitem guardar listas e objetos, e não só texto.
  • O valor padrão evita um null na primeira visita.
  • O retorno true ou false deixa a tela avisar quando não foi possível salvar.

Salvar enquanto digita, sem exagero (debounce)

Gravar a cada tecla é desperdício. Com um pequeno atraso, só a última digitação é salva:

let espera;
area.addEventListener('input', () => {
  nota.texto = area.value;
  clearTimeout(espera);
  espera = setTimeout(salvarNotas, 400);
});

Versão das chaves

Usei nomes como notas:v1. Se um dia o formato dos dados mudar, basta criar a v2 e migrar, sem quebrar quem já tem dados salvos.

Cuidados

  • Os dados ficam só naquele navegador e naquele aparelho. Para levar para outro lugar, ofereci o botão de baixar em .txt.
  • Nunca guarde senhas ou dados sensíveis no localStorage.
  • Limpar os dados do site apaga tudo. Vale avisar o usuário.
