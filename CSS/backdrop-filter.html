Usando backdrop-filter no CSS para Efeitos de UI Modernos

Fonte: CSS-Tricks

1. Introdução ao backdrop-filter

A propriedade CSS backdrop-filter permite aplicar efeitos visuais à área atrás de um elemento, criando:

  • Efeitos de vidro fosco (glassmorphism)
  • Overlays estilizados
  • Transições suaves de cor
  • Modais e diálogos modernos

2. Funções de Filtro Disponíveis

Função Exemplo Efeito
blur() blur(5px) Desfoque do fundo
brightness() brightness(120%) Ajuste de brilho
contrast() contrast(80%) Contraste do fundo
grayscale() grayscale(50%) Conversão para escala de cinza
hue-rotate() hue-rotate(90deg) Mudança de tonalidade

3. Exemplo: Efeito Vidro Fosco

.modal {
        background: rgba(255, 255, 255, 0.3);
        backdrop-filter: blur(10px) saturate(180%);
        border-radius: 12px;
        border: 1px solid rgba(255, 255, 255, 0.1);
        box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1);
    }

4. Suporte de Navegadores

  • Chrome 76+ ✅
  • Firefox 103+ ✅
  • Safari 9+ ✅
  • Edge 79+ ✅
  • Internet Explorer ❌
Nota: Para suporte mais amplo, use prefixo -webkit-backdrop-filter

5. Aplicações Práticas

5.1. Overlays de Navegação

.nav-overlay {
        position: fixed;
        top: 0;
        left: 0;
        width: 100%;
        backdrop-filter: blur(5px) brightness(90%);
    }

5.2. Cards Interativos

.card:hover {
        backdrop-filter: brightness(110%) contrast(120%);
        transition: backdrop-filter 0.3s ease;
    }

6. Considerações de Desempenho

Atenção: Efeitos muito intensos podem causar:
  • Redução na taxa de FPS
  • Consumo maior de memória
  • Problemas em dispositivos móveis
