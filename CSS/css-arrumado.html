CSS Arrumado

Contanto que você use o seletor correto e as propriedades apropriadas, você obtém seus estilos. No entanto, existe alguma ordem específica?

Você deve colocar isso position: relative;antes do color: limegreen;? É o contrário? Como você escreve essas propriedades?

Não há muitos posts e documentação sobre isso, mas se torna necessário para manutenção, principalmente quando você trabalha em equipe (ou várias).

A melhor maneira é definir suas diretrizes. Para sua inspiração, você pode usar o seguinte modelo:

.myelement {
    /* positioning */
        /* dimensions */
        /* text properties */
        /* borders & backgrounds */
        /* CSS3 magic */
}
