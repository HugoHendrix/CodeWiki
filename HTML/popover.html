📌 Popover API (HTML) + Cascade Layers (CSS)

🧠 O que é a Popover API?

A Popover API é um recurso moderno do HTML que permite criar elementos interativos (como menus, tooltips ou modais) sem precisar de JavaScript.

Introduzida no HTML Living Standard, essa API facilita o controle da visibilidade de elementos em resposta a ações do usuário (como clicar num botão).

🚀 Exemplo Prático

<button popovertarget="popover">Abrir Popover</button>
<div id="popover" popover>Conteúdo do popover</div>

✅ O que está acontecendo:

  • O botão com popovertarget="popover" controla a visibilidade do elemento com id="popover".
  • O atributo popover transforma a <div> em um elemento interativo que pode ser mostrado/ocultado automaticamente.

🎨 Estilizando com @layer

@layer style {
  #popover {
    background: var(--color-2); /* Cor de fundo definida em outro lugar */
    color: white;
    padding: 1em;
  }
}

Sobre @layer:

@layer é parte das Cascade Layers, uma nova funcionalidade do CSS que ajuda a organizar e controlar a ordem de prioridade entre estilos de diferentes origens (reset, temas, componentes, etc.).

📘 Explicação de atributos importantes

Atributo HTML Descrição
popover Torna o elemento interativo (pode ser exibido ou escondido).
popovertarget Indica qual elemento será controlado ao clicar no botão.
id Identificador do popover, usado para referenciar no botão.

🧱 Comparação: Antes e Depois

🔧 Antigo (com JS):

<button onclick="popover.classList.toggle('show')">Abrir</button>
<div id="popover" class="popover">Conteúdo</div>

✨ Novo (com Popover API):

<button popovertarget="popover">Abrir</button>
<div id="popover" popover>Conteúdo</div>
