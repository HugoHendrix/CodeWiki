🛠 Guia Rápido — Como identificar por que um site está fora do ar

1️⃣ Verificar se é um problema geral ou só no seu dispositivo

  • Teste o site em outro computador, celular ou rede de internet (Wi-Fi, 4G).
  • Use ferramentas online:
    • Down for Everyone or Just Me
    • Is It Down Right Now

2️⃣ Checar se o domínio está ativo

  • Acesse:
    • Registro.br (para domínios .br)
    • Who.is (para domínios internacionais)
  • Verifique:
    • Data de expiração do domínio.
    • Status (ativo ou expirado).
    • Servidores DNS configurados.

3️⃣ Testar o DNS

  • Use DNS Checker para verificar se o domínio está apontando corretamente.
  • Se não houver registros ou mostrar erros, pode ser problema de configuração ou propagação DNS.

4️⃣ Verificar o servidor

  • Peça para executar no terminal ou prompt: 
    ping seu-dominio.com

    Se não responder, o servidor pode estar offline.

  • Comando de rastreamento: 
    tracert seu-dominio.com   # Windows
traceroute seu-dominio.com # Mac/Linux

5️⃣ Conferir status da hospedagem

  • Acesse o painel da hospedagem (cPanel, Plesk ou outro).
  • Veja se há:
    • Mensagens de manutenção.
    • Bloqueio por falta de pagamento.
    • Erros nos logs.

6️⃣ Analisar mensagens de erro no navegador

  • ERR_NAME_NOT_RESOLVED → DNS/domínio.
  • ERR_CONNECTION_REFUSED → servidor offline.
  • HTTP 500, 502, 503 → erro interno no servidor.
  • Certificado inválido → problema no SSL.

7️⃣ Recuperar acesso ao Registro.br (caso tenha perdido o e-mail)

  • Se o titular do domínio perdeu o acesso ao e-mail cadastrado no Registro.br, será necessário seguir o procedimento oficial de reabilitação de conta.
  • Acesse o link oficial: Reabilitação de Conta – Registro.br
  • O Registro.br solicitará documentos para comprovar a titularidade e atualizar o e-mail de acesso.
  • Esse processo pode levar alguns dias, por isso é recomendável iniciar imediatamente para evitar que o domínio seja liberado para terceiros.

8️⃣ Próximos passos

  • Se for domínio expirado → renovar no provedor (Registro.br ou outro).
  • Se for problema de DNS → corrigir registros DNS.
  • Se for servidor → acionar a hospedagem.
  • Se for SSL vencido → renovar o certificado.
