📄 Documentação – Uso de JSON-LD e Schema.org no Site

1. O que é JSON-LD e por que usar?

O JSON-LD (JavaScript Object Notation for Linked Data) é um formato recomendado pelo Google para adicionar dados estruturados a páginas da web. Ele não é visível para o visitante, mas ajuda os buscadores (Google, Bing, etc.) a entender melhor o conteúdo do site. Isso melhora a indexação e possibilita a exibição de rich snippets (resultados enriquecidos), como:

  • Nome da empresa e logo no Google
  • FAQ expandida direto nos resultados
  • Endereço, telefone e outros dados de contato

📌 Referência oficial: https://schema.org/

2. Principais tipos de Schema usados no site

2.1 Organization

Fornece informações sobre a empresa:

  • Nome
  • Site oficial
  • Logo
  • Endereço
  • País

Esse código deve estar preferencialmente no início da página (geralmente no <head>).

<script type="application/ld+json">
{
  "@context": "http://schema.org",
  "@type": "Organization",
  "name": "Nome da Empresa",
  "url": "https://www.exemplo.com.br",
  "logo": {
    "@type": "ImageObject",
    "url": "https://www.exemplo.com.br/imagens/logo.png",
    "width": "1000",
    "height": "1000"
  },
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "Rua Exemplo, 123",
    "addressLocality": "Cidade",
    "addressRegion": "Estado",
    "postalCode": "00000-000",
    "addressCountry": {
      "@type": "Country",
      "name": "BR"
    }
  }
}
</script>

2.2 FAQPage

Permite exibir perguntas e respostas diretamente nos resultados do Google. Esse código pode ser inserido no final da página ou no local onde as perguntas/respostas aparecem no HTML. 

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "Pergunta exemplo?",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "Resposta exemplo."
    }
  }]
}
</script>

3. Como validar os dados estruturados

Antes de publicar, valide o código no Teste de Resultados Avançados do Google:

🔗 https://search.google.com/test/rich-results

  1. Acesse o link acima.
  2. Cole a URL da página ou o código JSON-LD.
  3. Verifique se não há erros.
  4. Publique a página corrigida, se necessário.

4. Boas práticas

  • Sempre manter o JSON-LD atualizado com as informações reais da empresa.
  • Evitar dados falsos ou desatualizados (o Google pode penalizar).
  • Usar o formato JSON-LD em vez de Microdata ou RDFa (é o formato recomendado pelo Google).
  • Testar todas as páginas importantes do site.
