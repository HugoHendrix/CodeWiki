Atalho Descrição
CTRL + F5 Atalho comumente usado em navegadores da web para forçar a recarga da página sem usar o cache do navegador. Útil ao desenvolver ou visualizar alterações em um site, garantindo que você esteja vendo a versão mais recente da página.
Bandeira do Windows + Pause Break Abre a janela de propriedades do sistema no Windows, exibindo informações sobre o seu computador, como nome, quantidade de memória RAM e tipo de processador. Permite acessar rapidamente informações básicas sem navegar por várias configurações do sistema.
CTRL + SHIFT + M Abre o modo mobile no navegador FireFox.
Bandeira do Windows + E Abre uma nova janela do Explorador de Arquivos no Windows, permitindo que você navegue rapidamente pelo sistema de arquivos do seu computador. Útil para acessar documentos, mídia, programas e outras pastas ou unidades de armazenamento.
Shift + Delete Exclui permanentemente um arquivo ou pasta no Windows, ignorando a etapa da Lixeira. Cuidado ao usar, pois os arquivos excluídos desta maneira não podem ser recuperados facilmente.
Bandeira do Windows + R Abre a caixa de diálogo "Executar" no Windows.
CRTL + U Exibe o código fonte no navegador.
ALT + SHIFT + F Formatação automática do código
CTRL + D Seleciona elementos iguais
CTRL + L Seleciona a linha atual
CTRL + SHIFT + K Deletar linha
CTRL + G (VS CODE) Dentro VS Code, use para localizar o número da linha de código.
