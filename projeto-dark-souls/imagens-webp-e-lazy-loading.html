Imagens em WebP e carregamento preguiçoso

O Projeto Dark Souls tinha cerca de 4 MB de imagens, entre PNG e JPG, e até um arquivo .zip dentro da pasta de assets. Esta anotação mostra como converti tudo para WebP e o que mudou no HTML e no CSS.

Antes e depois

Item Antes Depois
Imagens convertidas 46 arquivos PNG e JPG (3,4 MB) 46 arquivos WebP (2,5 MB)
Pasta assets 4,0 MB, com um .zip 2,7 MB, sem o .zip

Conversão com Python

Usei a biblioteca Pillow para converter tudo de uma vez, limitando a largura a 1920 px:

import glob, os
from PIL import Image

for caminho in glob.glob('assets/images/**/*', recursive=True):
    if not caminho.lower().endswith(('.jpg', '.jpeg', '.png')):
        continue
    imagem = Image.open(caminho)
    transparente = imagem.mode in ('RGBA', 'LA', 'P')
    imagem = imagem.convert('RGBA' if transparente else 'RGB')
    if imagem.width > 1920:
        imagem = imagem.resize((1920, round(imagem.height * 1920 / imagem.width)))
    imagem.save(os.path.splitext(caminho)[0] + '.webp', 'WEBP', quality=82, method=6)
  • quality=82 manteve boa aparência com bastante economia.
  • Conservar o canal alfa (RGBA) é importante para logos e ícones com fundo transparente.

Atualizar as referências

Depois de converter, é preciso trocar a extensão em todos os lugares que citam as imagens: HTML, CSS e JavaScript. Eu apaguei os originais e fiz um script que conferia se todo caminho citado ainda existia.

O erro que o script pegou: duas imagens de fundo no CSS estavam escritas com barra dupla (images//background/), então a troca automática não as encontrou.

O que não converter

  • A imagem de compartilhamento (og:image) fica em JPG ou PNG, porque nem todas as redes sociais aceitam WebP.
  • O favicon também fica em PNG ou SVG.

Carregamento preguiçoso

O atributo loading="lazy" adia o download das imagens que estão fora da tela. Coloque também width e height para o navegador reservar o espaço e evitar que o layout pule.

<img src="assets/images/wallpaper/wallpaper-anor-londo.webp"
     width="1920" height="1080" loading="lazy"
     alt="Catedral de Anor Londo iluminada pelo sol">
  • Não use lazy na imagem principal do topo da página, porque ela precisa carregar logo.
  • Em abas escondidas com hidden, as imagens lazy só são baixadas quando a aba aparece.
