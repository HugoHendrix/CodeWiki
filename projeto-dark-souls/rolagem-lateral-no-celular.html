Como encontrar e corrigir rolagem lateral no celular

Ao testar o Projeto Dark Souls em uma tela de 375 px, a página tinha 1136 px de largura. O usuário precisava rolar para o lado para ler o texto. Esta anotação mostra como achei o problema e o que corrigi.

1. Confirmar o problema

No DevTools, ative o modo responsivo (Ctrl + Shift + M), escolha uma largura de 375 px e rode no console:

({
  janela: document.documentElement.clientWidth,
  pagina: document.documentElement.scrollWidth
})

Se pagina for maior que janela, existe rolagem lateral.

2. Achar o elemento culpado

const largura = document.documentElement.clientWidth;
[...document.querySelectorAll('body *')]
  .filter(el => el.getBoundingClientRect().right > largura + 2)
  .slice(0, 10)
  .map(el => el.tagName + '.' + el.className);

O script lista os elementos que passam da borda da tela. O primeiro costuma ser a causa, e os outros são efeito dele.

3. O que estava errado e como corrigi

Causa Correção
Texto com width: 92ch width: 100%; max-width: 92ch;
Formulário com width: 620px width: 100%; max-width: 800px;
Menu e botões em display: flex sem quebra de linha Adicionar flex-wrap: wrap
Título em 4rem fixos font-size: clamp(2.2rem, 8vw, 4rem)
Altura do rodapé em height: 50% Remover a altura e usar padding

4. Ajustes específicos para telas pequenas

@media (max-width: 768px) {
  .container-fluid { padding: 2rem 1rem; }
  .content { width: 100%; padding: 1.5rem 1rem; }
  .nav-buttons { flex-direction: column; }
  p { text-align: left; }   /* texto justificado em tela estreita gera buracos */
}

Regras para evitar o problema

  • Prefira max-width a width fixa.
  • Use flex-wrap: wrap em qualquer linha de itens.
  • Use clamp() para tipografia que acompanha a tela.
  • Teste em 375 px antes de publicar, e não só no tamanho do seu monitor.
  • Evite esconder o problema com overflow-x: hidden no body. Ele corta o conteúdo, não corrige a causa.

Resultado

A largura da página passou de 1136 px para 375 px, sem rolagem lateral, e o mesmo script voltou lista vazia.
