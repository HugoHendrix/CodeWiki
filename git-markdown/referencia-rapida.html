Referência Rápida de Git

Fonte: freeCodeCamp

1. Comandos Básicos do Git

Comando Descrição
git init Inicializa um novo repositório Git
git clone [url] Clona um repositório de uma URL remota
git status Mostra o status da árvore de trabalho
git add [arquivo] Adiciona conteúdo do arquivo ao índice
git commit -m "[mensagem]" Registra alterações no repositório

2. Ramificações (Branches) e Mesclagem

Comando Descrição
git branch Lista todos os branches locais
git branch [nome-do-branch] Cria um novo branch
git checkout [nome-do-branch] Muda para outro branch
git merge [branch] Mescla o branch especificado com o branch atual
git branch -d [nome-do-branch] Exclui um branch
Dica: Use git checkout -b [nome-do-branch] para criar e mudar para um novo branch em um único comando.

3. Repositórios Remotos

Comando Descrição
git remote add [nome] [url] Adiciona um novo repositório remoto
git fetch [remoto] Baixa objetos do repositório remoto
git pull [remoto] [branch] Busca e integra com outro repositório
git push [remoto] [branch] Atualiza referências remotas com objetos associados
git remote -v Lista todos os repositórios remotos
Observação: git pull é equivalente a git fetch seguido por git merge.

4. Desfazendo Alterações

Comando Descrição
git reset [arquivo] Remove um arquivo da área de stage mantendo as alterações
git reset --hard [commit] Redefine o HEAD atual para o estado especificado (cuidado!)
git checkout -- [arquivo] Descarta alterações no diretório de trabalho
git revert [commit] Cria novo commit que desfaz alterações
Aviso: git reset --hard irá excluir permanentemente alterações não commitadas. Use com cautela!

5. Comandos Avançados

Comando Descrição
git stash Armazena temporariamente alterações sem commit
git rebase [branch] Reaplica commits em cima de outra base
git cherry-pick [commit] Aplica alterações de um commit específico
git bisect Busca binária para encontrar commit que introduziu um bug
git submodule Gerencia submódulos do projeto

6. Apelidos Úteis (Aliases)

# Adicione isso ao seu arquivo ~/.gitconfig
[alias]
    co = checkout
    br = branch
    ci = commit
    st = status
    last = log -1 HEAD
    unstage = reset HEAD --
    lg = log --graph --pretty=format:'%Cred%h%Creset -%C(yellow)%d%Creset %s %Cgreen(%cr) %C(bold blue)<%an>%Creset' --abbrev-commit --date=relative
