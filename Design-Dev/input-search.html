🔍 O que faz o <input type="search">

É um campo de texto otimizado para buscas. Ele se comporta quase como um type="text", mas com recursos nativos adicionais voltados à experiência do usuário e acessibilidade.

✅ 1. Botão de limpar nativo (×)

Nos navegadores modernos (principalmente Safari, Chrome e Edge), o campo de busca exibe automaticamente um botão “×” à direita quando o usuário digita algo. Clicar nesse botão limpa o campo instantaneamente, sem precisar de JavaScript.

✅ 2. Acessibilidade integrada

Ele já vem com a semântica de “campo de pesquisa”. Isso significa que leitores de tela entendem que o usuário está interagindo com uma busca, sem precisar adicionar aria-label ou role="searchbox" manualmente (embora seja possível adicionar para reforço).

✅ 3. Teclado otimizado em dispositivos móveis

Em smartphones e tablets, o teclado muda automaticamente para um layout otimizado para pesquisa, com um botão “Search” ou “Go”, tornando a experiência mais fluida.

✅ 4. Compatível com atributos avançados

O input type="search" funciona com atributos que melhoram a usabilidade:

  • enterkeyhint="search" → controla o texto do botão “Enter” no teclado virtual.
  • incremental → permite enviar eventos conforme o usuário digita (sem precisar pressionar Enter).
  • role="search" → reforça a semântica da área de busca.

Exemplo mais completo:

<form role="search">
  <input 
    type="search" 
    placeholder="Buscar no site..." 
    enterkeyhint="search" 
    incremental 
  />
</form>

💡 Dica extra

Se quiser estilizar o botão “×”, ele é controlado por pseudoelementos específicos de cada navegador (por exemplo, ::-webkit-search-cancel-button em navegadores baseados em Chromium e Safari).
