🧭 Performance API – Medindo o Tempo de Execução com Precisão

A Performance API é uma ferramenta nativa do navegador projetada para medir tempos de execução de forma precisa, ideal para otimizar o desempenho de scripts, animações e renderizações. Diferente de console.time(), ela oferece medições de alta resolução, não bloqueia a thread principal e integra-se diretamente às ferramentas de desenvolvimento.

⚙️ Exemplo básico

performance.mark('start');

// Código a ser medido
for (let i = 0; i < 1_000_000; i++) {
  Math.sqrt(i);
}

performance.mark('end');
performance.measure('render', 'start', 'end');

// Exibindo resultado
console.log(performance.getEntriesByName('render')[0].duration);

🧩 Explicação passo a passo:

  1. performance.mark('start') → cria uma marca temporal chamada “start”.
  2. Executa o código que você quer medir.
  3. performance.mark('end') → cria uma segunda marca.
  4. performance.measure('render', 'start', 'end') → calcula a diferença entre as marcas.
  5. performance.getEntriesByName('render') → retorna informações detalhadas, incluindo a duração em milissegundos (com precisão de microssegundos).

🔍 Saída esperada

PerformanceMeasure {
  name: "render",
  entryType: "measure",
  startTime: 125.23,
  duration: 4.87
}

A propriedade duration indica o tempo total de execução do código medido.

📊 Visualizando nas DevTools

Os resultados também podem ser vistos em DevTools → Performance → Timings (cada marca e medição aparece no registro da linha do tempo).

⚡ Por que usar a Performance API

Característica console.time() performance.mark()
Precisão Milissegundos Submilissegundo
Bloqueia thread principal Sim Não
Visualização no DevTools Não Sim
Funciona com async code Difícil Sim
Integração com observadores Não Sim (PerformanceObserver)

🧠 Limpeza e boas práticas

Depois de medir, é uma boa prática limpar as marcas para não acumular dados desnecessários: 

performance.clearMarks();
performance.clearMeasures();

🔭 Monitoramento em tempo real

Com PerformanceObserver, você pode observar as medições automaticamente:

const observer = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    console.log(`${entry.name}: ${entry.duration.toFixed(2)}ms`);
  }
});

observer.observe({ entryTypes: ['measure'] });

Agora, toda nova medição será registrada em tempo real.

💡 Dica avançada

Você pode criar funções utilitárias para medir facilmente qualquer bloco de código:

function medirTempo(nome, fn) {
  performance.mark(`${nome}-start`);
  fn();
  performance.mark(`${nome}-end`);
  performance.measure(nome, `${nome}-start`, `${nome}-end`);
  const tempo = performance.getEntriesByName(nome).pop().duration;
  console.log(`${nome}: ${tempo.toFixed(3)}ms`);
  performance.clearMarks();
  performance.clearMeasures();
}

Uso:

medirTempo('loop pesado', () => {
  for (let i = 0; i < 1_000_000; i++) Math.pow(i, 2);
});
